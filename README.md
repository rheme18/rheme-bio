# 🌌 Rheme Bio / Portfolio Template

A modern, ultra-lightweight, minimalist, and dark-themed **Link-in-Bio / Personal Portfolio** template inspired by custom aesthetic platforms like Guns.lol. Built for developers, creators, and minimalists who want a clean, lightning-fast personal landing page.

---

### ✨ Features
* **Minimalist Dark Aesthetics:** Pure dark-mode styling optimized for speed and a sleek visual vibe.
* **Ambient Video Background:** Smooth loop video integration via HTML5.
* **Integrated Music Player:** Custom play/pause audio controls with adjustable volume slider.
* **Interactive About Modal:** Full-screen responsive drawer featuring a biography and live GitHub contribution chart (`ghchart`).
* **SEO & Schema Markup:** Fully optimized with JSON-LD `Person` schema markup for Google search entity recognition.
* **Fully Responsive:** Perfectly optimized for both desktop and mobile viewports.

---

### 🚀 Tech Stack
* **HTML5 / CSS3 / JavaScript (Vanilla):** Zero heavy frameworks, maximum performance and instant load times.
* **Hosted on:** Vercel / GitHub Pages.

---

### 🛠️ Customization Guide

To personalize the portfolio with your own media, simply replace the files inside the `pictures/` folder using the exact same file names and formats:

| File Name | Format | Description |
| :--- | :--- | :--- |
| **`banner.mp4`** | `.mp4` | Ambient background video loop |
| **`pfp.jpg`** | `.jpg` | Profile picture displayed in the center |
| **`music.mp3`** | `.mp3` | Background audio track played by the built-in player |
| **`favicon.jpg`** | `.jpg` | Browser tab icon |

> **Pro Tip:** Keep the exact file names and extensions listed above so you won't need to modify any path references in `index.html`.
